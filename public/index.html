YT Clip Editor

Cut, clip, and package YouTube footage — Quran recitations, viral clips, and talking-head edits.

Quran Clips

Paste a prayer summary, cut Surah clips, get YouTube titles and descriptions.

Local UI → http://localhost:8767

venv\Scripts\python tools\quran_clips\server.py

Clip Factory

Viral clips, compilations, scene detection, and full exports.

Local UI → http://localhost:8766

venv\Scripts\python tools\clip_factory\server.py

Cut Editor

Review and refine cuts on talking-head footage.

Local UI → http://localhost:8765

venv\Scripts\python tools\editor\server.py

Setup (once)

git clone https://github.com/amillioner/youtube-editor
cd youtube-editor
py -m venv venv
venv\Scripts\python -m pip install -r requirements.txt
copy .env.example .env

Requires ffmpeg, node, and API keys in .env. See the repo README.

Video processing runs locally (ffmpeg, Python). This site is the project home — run the servers above on your machine to use the editors.
